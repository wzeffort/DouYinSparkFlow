# 任务容量、用户额度与平台运行看板设计

## 目标

在保持单 Web、单 Worker 串行执行架构的前提下，限制定时任务集中拥堵和普通用户恶意堆积任务，并让所有已登录用户看到不含个人信息的今日运行概览。

## 范围

本次包含三项相互关联的能力：

1. 普通用户任务数量额度及管理员单用户调整。
2. 全平台两分钟执行时段容量及空闲时间推荐。
3. 所有已登录用户可见的全平台今日运行看板。

不增加并行浏览器，不公开用户名、抖音账号、好友、消息内容或邀请码，不自动移动已有任务。

## 任务额度

- 普通用户默认最多保留 5 个任务，启用和暂停任务均计入。
- 管理员账号不受普通用户额度限制。
- 新增独立的用户任务额度记录，以用户 ID 为主键；没有记录时继承默认值 5。
- 管理员可在用户管理区域设置 1–100 的个人任务上限。
- 管理员把额度调低到用户当前任务数以下时，不删除、不暂停已有任务；该用户只有在任务数降到额度以下后才能继续创建。
- 创建任务时服务层重新统计并校验，不能依赖前端提示。
- 达到额度时显示“当前任务 5/5，请删除任务或联系管理员提高额度”。

## 两分钟执行时段

- 使用北京时间的每日时刻划分时段：`00:00–00:01`、`00:02–00:03`，依此类推。
- 每个时段全平台最多有 1 个启用任务；暂停任务不占用时段。
- 新建任务、编辑发送时间、重新启用任务时都进行容量检查。
- 编辑任务时忽略任务自身；管理员操作与普通用户操作执行相同容量规则。
- 现有已启用任务不自动调整。若上线前已经存在同一时段的任务，它们继续保留，但该时段不再接受新任务。
- 当前部署只有一个 Web 进程。容量检查在统一任务服务和进程内临界区中完成，并在同一数据库事务内再次查询；所有写入口必须经过该服务。
- 若未来扩展为多个 Web 进程，应升级为数据库唯一时段预约表；本次不为尚不存在的部署形态增加额外状态表。

### 空闲时间推荐

- 提供已登录接口查询指定时间的时段状态，仅返回剩余名额和邻近空闲时间。
- 时段已满时，从当前时段向前、向后按两分钟搜索，返回距离最近且未被占用的 3 个时间。
- 任务页面在用户选择时间后立即显示 `剩余 1/1` 或 `剩余 0/1`，并展示推荐时间按钮。
- 最终提交仍以服务端校验结果为准，防止绕过页面。

### 自动重试

- Worker 临时故障重试、重新登录后的安全补跑、管理员安全重试都通过同一个“下一空闲执行时间”函数安排。
- 自动重试从原计划的最早重试时间开始，按两分钟向后寻找未被正常任务或已安排重试占用的时段。
- 自动重试不创建新任务，因此不消耗用户任务额度。
- 已进入发送或确认阶段的失败仍不自动重试，继续避免重复消息。

## 今日运行看板

### 可见性

- 仅已登录用户可以访问页面和统计接口。
- 管理员与普通用户看到相同的全平台汇总数字。
- 响应中不包含任何用户、账号、好友或消息标识。

### 统计口径

- 时区固定为 `Asia/Shanghai`，统计当天 00:00 至次日 00:00。
- 今日总任务：当前全平台启用任务数量。因为任务每日执行，每个启用任务每天应执行一次。
- 对每个启用任务只取今天最新一次执行记录：
  - `success` 计入成功；
  - `running` 计入正在执行；
  - `failed` 或 `skipped` 计入失败/跳过；
  - 今天尚无执行记录的计入待执行。
- 同一任务先失败后补跑成功，最终只计入成功。
- 首页主指标显示“今日成功 4/10”，并分别显示正在执行、待执行、失败/跳过。
- 系统状态根据 Worker 租约判断：租约有效显示“正常运行”，无租约或租约过期显示“执行器暂时离线”。

### 动态更新

- 新增已登录统计 JSON 接口。
- 首页初次响应直接渲染统计，避免 JavaScript 加载前空白。
- 页面每 15 秒请求一次统计接口并更新数字、进度和状态；请求失败时保留上次数据并显示“状态更新暂时失败”，不把统计清零。

## 管理后台与任务页面

- 用户管理卡片显示该用户当前任务数和上限，并提供额度编辑表单。
- 普通任务页显示“已使用 X/Y 个任务”。
- 时间输入区域显示两分钟时段说明、剩余名额和推荐空闲时间。
- 所有错误使用明确中文提示，不暴露数据库或执行器内部异常。

## 数据与兼容性

- 新增额度表通过现有 `create_schema` 创建，不修改用户表，不影响已有用户数据。
- 没有额度记录的所有现有普通用户自动继承默认值 5。
- 现有任务、执行历史、抖音账号和登录凭据保持不变。
- 上线前备份 SQLite 数据库和相关代码；只重建需要新代码的容器。

## 测试

- 服务测试覆盖默认额度、个人额度、暂停任务计数、管理员豁免及降低额度不删除数据。
- 时段测试覆盖边界、跨小时、编辑自身、暂停释放、重新启用、管理员入口及邻近时间推荐。
- 并发测试覆盖同一进程内两个同时提交只有一个成功。
- 重试测试覆盖正常任务占用时自动寻找下一空闲时段，且不改变重复发送安全边界。
- Web 测试覆盖普通用户和管理员的统计可见性、未登录拒绝、响应脱敏、北京时间日界线和 15 秒动态刷新所需的数据契约。
- 部署前运行完整测试套件，部署后检查 Web 健康、Worker 租约、容器重启次数和线上统计接口。
